## Sobre o Projeto

O AlertaBairro é um aplicativo desenvolvido em Flutter e Dart, com o objetivo de auxiliar moradores no acompanhamento de situações de risco relacionadas a chuvas fortes e alagamentos.

A aplicação apresenta informações sobre regiões monitoradas, alertas de risco e orientações de segurança, contribuindo para a prevenção e a conscientização da população.

## Telas / Funcionalidades 

- **Cadastro de moradores:** formulário para registro de dados pessoais e endereço, com validação dos campos.
- **Tela inicial:** apresentação de informações e alertas sobre a região.
- **Monitoramento de regiões:** visualização dos níveis de risco das regiões cadastradas.
- **Detalhes das regiões:** apresentação do nível da água e orientações de segurança.
- **Alertas:** exibição de avisos sobre chuvas fortes, risco de alagamento e condições normais.
- **Interatividade:** navegação entre telas e opção de marcar alertas como lidos.

## Como Executar o Projeto

**1.** Clone o repositório:

```bash
git clone https://github.com/manuellarinaldi/alerta_bairro.git
```

**2.** Acesse a pasta do projeto:

```bash
cd alerta_bairro
```

**3.** Instale as dependências:

```bash
flutter pub get
```

**4.** Execute o aplicativo:

```bash
flutter run
```

## Observação

Esta versão utiliza dados simulados para demonstrar as funcionalidades do aplicativo. Portanto, as informações apresentadas não correspondem a medições ou alertas oficiais em tempo real.

## Objetivo

Contribuir para a prevenção de riscos relacionados a chuvas e alagamentos, facilitando o acesso à informação e incentivando a segurança dos moradores.
